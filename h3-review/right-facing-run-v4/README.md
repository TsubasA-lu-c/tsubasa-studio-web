# MiniMax H3 right-facing run review

This is an unapproved, browser-based review bundle for the SPAG H3 motion
redraw probe. Open `index.html` for frame-by-frame review.

- `source/`: selected concrete H3 frames, motion authority
- `redraw/`: canonical swordless redraw probe, not adopted artwork
- `canonical-reference.png`: 4.40H identity/style reference
- `source-vs-redraw-4x2.png`: static comparison sheet
- `canonical-redraw-loop-provisional-100ms.apng`: provisional loop preview

The current probe focuses on source-derived horizontal/vertical registration
and keeping both arms visible through body overlap. Arm identity and artwork
acceptance still require human review. Weapon attachment and Unity integration
are not started.
